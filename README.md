# Прогнозирование MCC-кодов по истории банковских транзакций

Командный проект для конкурса ВШЭ **«Твой проект»** по направлению **«Интеллектуальный анализ данных»**.

## Описание задачи

В проекте решалась задача прогнозирования следующих покупок клиента по истории банковских транзакций.

Для каждого объекта наблюдения дана последовательность MCC-кодов в хронологическом порядке. Необходимо по истории операций предсказать следующие 8 MCC-кодов.

Задача близка к постановкам:

- sequential prediction;
- next-purchase prediction;
- next-basket recommendation;
- рекомендательные системы для транзакционных данных.

## Важное замечание о формате проекта

Весь проект находится в одном Jupyter Notebook, так как это было условием конкурса.  
Описание, анализ данных, эксперименты, модели, метрики и выводы также приведены внутри ноутбука на русском языке.
