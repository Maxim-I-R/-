# Прогнозирование MCC-кодов по истории банковских транзакций

Командный проект для конкурса ВШЭ **«Твой проект»** по направлению **«Интеллектуальный анализ данных»**.

## Описание задачи

В проекте решалась задача прогнозирования последовательности следующих покупок клиента по истории банковских транзакций.

Для каждого объекта наблюдения дана последовательность MCC-кодов в хронологическом порядке. Необходимо по истории операций предсказать следующие 8 MCC-кодов в правильной последовательности.

Задача близка к следующим постановкам:

- sequence modeling;
- time series forecasting;
- next-purchase prediction;
- next-basket recommendation;
- рекомендательные системы для транзакционных данных.

## Важное замечание о формате проекта

Весь проект находится в одном Jupyter Notebook, так как это было условием конкурса.  
Описание, анализ данных, эксперименты, модели, метрики и выводы также приведены внутри ноутбука на русском языке.

Основной файл проекта:

```text
team_11_iad_solution.ipynb
```

## Мой вклад

В рамках проекта я отвечал за:

- выбор и обоснование метрик качества;
- валидацию решений;
- проверку решения на соответствие критериям конкурса и общим ML-практикам: наличие абляций, бейзлайнов, отсутствие утечек данных;
- поиск и анализ релевантных статей по next-purchase prediction, next-basket recommendation и sequence modeling;
- разработку собственной модели **Tail-Focused Embedding Architecture** — надстройки над предобученными эмбеддингами MCC-кодов;
- анализ результатов модели и сравнение с альтернативными подходами.
